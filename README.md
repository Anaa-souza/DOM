## 📌 Sobre o Projeto

Este projeto reúne atividades práticas de **manipulação do DOM (Document Object Model)** utilizando **JavaScript puro**, com o objetivo de entender como interagir com elementos HTML de forma dinâmica.

## 📂 Estrutura das Atividades

### 🟢 Atividade 1 — Adicionar Item na Lista

📌 **Funcionalidade:**
- Ao clicar no botão, um novo `<li>` é criado e adicionado na lista.

💡 **Aprendizado:**
- Manipulação direta do DOM  
- Criação dinâmica de elementos  

---

### 🔵 Atividade 2 — Criar Lista com Loop

📌 **Funcionalidade:**
- Ao clicar no botão, são criados vários itens automaticamente (de 1 a 5).

💡 **Aprendizado:**
- Uso de estruturas de repetição  
- Introdução ao `DocumentFragment` para melhorar performance  

---

### 🟣 Atividade 3 — Mostrar Nomes com Array

📌 **Funcionalidade:**
- Um array de nomes é percorrido  
- Cada nome vira um item da lista  

💡 **Aprendizado:**
- Integração entre **JavaScript + DOM**  
- Uso de `forEach`  
- Manipulação eficiente com `DocumentFragment`  

---

## ⚡ Destaque: DocumentFragment

O `DocumentFragment` permite criar vários elementos **fora da árvore principal do DOM**, evitando múltiplas renderizações e melhorando a performance.
